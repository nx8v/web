Jalankan JavaScript.

NX8V adalah runtime JavaScript open source dalam satu binary C++ — mesin V8, event loop libuv, HTTP/HTTPS, WebSocket, router, hingga jendela desktop. Satu perintah, tanpa dependensi, tanpa setup.

Mulai Sekarang Lihat Contoh

C++17 · mesin V8 · libuv · satu executable

Fitur

API inti yang tersedia langsung di dalam runtime.

Eksekusi script & REPL

Jalankan nx8v script.js atau masuk REPL interaktif dengan nx8v tanpa argumen.

Event loop libuv

Promise dan async/await bekerja secara native lewat microtask pump.

require() & ES Modules

CommonJS dengan cache (__filename, __dirname) plus import/export untuk file .mjs.

fetch HTTPS & router

Fetch Promise-based HTTP/HTTPS, dan router ala Express dengan req.params serta middleware.

WebSocket & stream

Server + client WebSocket (RFC 6455), dan stream Readable/Writable/Duplex dengan pipe.

Tooling, test & desktop

nx8v init/dev/start/stop/list, test runner bawaan (test/assert), dan nx8v window untuk jendela desktop WebView2.

Modul built-in

Dua belas modul siap dipanggil lewat require(), tanpa instalasi tambahan.

Contoh kode

Simpan sebagai file .js lalu eksekusi dengan nx8v.

const http = require('http');

http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Halo dari NX8V!');
}).listen(8080, () => console.log('listening on :8080'));
const EventEmitter = require('events');

const em = new EventEmitter();
em.on('sapa', (nama) => console.log(`Hai, ${nama}!`));
em.emit('sapa', 'dunia');
const res = await fetch('https://api.github.com/users/octocat');

if (res.ok) {
  const user = await res.json();
  console.log(user.name);
}
const crypto = require('crypto');

console.log(crypto.createHash('sha256').update('nx8v').digest('hex'));
console.log(crypto.randomUUID());

Mulai dalam 60 detik

Tiga langkah dari nol sampai HTTP server berjalan.

  1. 1. Pasang sekali

    Binary masuk ke PATH user dan dapat dipanggil dari direktori mana pun.

    powershell -ExecutionPolicy Bypass -File D:\NX8V\install.ps1

  2. 2. Buat proyek

    Wizard menghasilkan project.json, server.js, dan folder public/.

    cd D:\proyek-saya
nx8v init

  3. 3. Jalankan

    Server statik aktif beserta contoh endpoint GET /api/hello.

    nx8v server.js
