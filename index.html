01 / PLATFORM

Satu runtime. Setiap lapisan produk.

Tidak perlu menyatukan banyak tool hanya untuk menjalankan satu ide. NX8V memberi fondasi yang sama untuk backend, frontend, data, dan desktop.

01

Server & API

Buat layanan web dengan HTTP/HTTPS, router, WebSocket, middleware, static files, dan endpoint JSON.

nx8v start
Pelajari server →
02

Data & Integrasi

Mulai dari localStorage dan SQLite hingga MySQL, PostgreSQL, Firebase, REST API, dan proxy.

require('db')
Lihat modul data →
03

Desktop Native

Gunakan HTML, CSS, dan JavaScript yang sama dalam jendela WebView2 dengan dialog, tray, notifikasi, dan packaging.

nx8v window
Pelajari desktop →

03 / DEVELOPER WORKFLOW

Dari ide ke aplikasi, tanpa pindah konteks.

Tooling sederhana untuk siklus yang nyata: buat, kembangkan, uji, lalu distribusikan.

01

Init

Buat project dengan struktur yang siap dijalankan.

nx8v init
02

Develop

Simpan file dan lihat perubahan tanpa setup bundler.

nx8v dev
03

Test

Jalankan test bawaan untuk menjaga perilaku aplikasi.

nx8v test
04

Ship

Jalankan di server atau paketkan sebagai desktop app.

nx8v package
terminal
# create a project
